onnx-cardputer-flash

Flashes a TFLite Micro firmware image to an ESP32-S3 board (e.g. M5Stack Cardputer) straight from the browser over Web Serial. See ../README.md for the full pipeline (Hugging Face model → onnxsim simplify/quantize → TFLite Micro conversion → this page).

1. Get a model

Fetch and simplify/quantize a Hugging Face ONNX model with the onnxsim model converter, then download the result. This page doesn't repeat that UI — it picks back up at step 3 below, offline.

Candidates (Cardputer has a mic, no camera, so these are all audio models; sizes are the actual model.onnx size on the Hub). Each link opens the converter pre-filled with that model.

ModelSizeWhy
tensorflow-Micro-Speech-TinyConv-SpeechCommands-uint8-onnx 19 KB Google's official micro_speech reference (yes/no + a few words) — smallest, best first end-to-end test
mlcommons-DS-CNN-SpeechCommands-int8-onnx 74 KB MLPerf Tiny's official keyword-spotting benchmark model
mlcommons-Streaming-Wakeword-DS-CNN-SpeechCommands-int8-onnx 72 KB Streaming variant — closer to real "always-listening" wake-word behavior
arm-DS-CNN-Large-SpeechCommands-clustered-int8-onnx 476 KB ARM's larger KWS reference — more accuracy if you have the flash budget
mlcommons-Deep-Autoencoder-DCASE2020-ToyCar-int8-onnx 285 KB Anomaly-sound detection (autoencoder + reconstruction-error threshold) — a different task, still mic-only

These are community re-exports (the ketiswp Hub org), not the original MLCommons/Google/ARM accounts — spot-check one with the converter's own Netron/inference panel before trusting it on hardware.

2. Flash the generic runtime (once per board)

Download cardputer-runtime.bin — a real, compiled, checksummed TFLite Micro runtime (see ../firmware/runtime/README.md). Flash it at address 0x0 below. You only do this once: it reads whatever model currently sits in a fixed flash partition at boot, so swapping models later (step 4) never touches this again.

3. Convert your model to .tflite (offline, local machine)

Not done in-browser: pip install onnx2tf, then python3 ../scripts/onnx_to_tflite_micro.py your_model.onnx model.tflite. Bring the resulting model.tflite back here — it must fit in the runtime's 1MB model partition (every candidate in step 1's table does).

4. Flash over Web Serial

This browser has no navigator.serial — try Chrome or Edge (desktop), 89+.

Same Connect session for both: flash cardputer-runtime.bin at 0x0 (step 2, once), then flash your model.tflite at 0x310000 (step 4, every time you swap models) — pick the file, set the address, Flash; repeat for the second file without reconnecting.
