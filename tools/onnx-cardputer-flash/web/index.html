onnx-cardputer-flash

Flashes a TFLite Micro firmware image to an ESP32-S3 board (e.g. M5Stack Cardputer) straight from the browser over Web Serial. See ../README.md for the full pipeline (Hugging Face model → onnxsim simplify/quantize → TFLite Micro conversion → this page).

1. Get a model

Fetch and simplify/quantize a Hugging Face ONNX model with the onnxsim model converter, then download the result. This page doesn't repeat that UI — it starts from step 2 below, offline.

2. Convert to a flashable firmware image (offline, local machine)

Not done in-browser — see ../scripts/onnx_to_tflite_micro.py (ONNX → TFLite → C array) and ../firmware/README.md (build a merged .bin with the model baked in). Bring the resulting .bin back here.

3. Flash over Web Serial

This browser has no navigator.serial — try Chrome or Edge (desktop), 89+.





(0x0 for ESP32-S3 boards like Cardputer — the bootloader offset differs on classic ESP32)
