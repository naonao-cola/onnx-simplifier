onnx-k210-flash

Flashes a firmware image to a Kendryte K210 board (M5StickV, Sipeed Maix Amigo) over Web Serial, using k210_isp.mjs -- a from-scratch port of kflash.py's ISP protocol. See ../README.md for status (short version: reviewed against kflash.py's source and unit-tested at the framing level, not yet run against a real board).

This browser has no navigator.serial -- try Chrome or Edge (desktop), 89+.
