onnx-k210-flash

Flashes a firmware image to a Kendryte K210 board (M5StickV, Sipeed Maix Amigo) over Web Serial, using k210_isp.mjs -- a from-scratch port of kflash.py's ISP protocol. See ../README.md for status (short version: reviewed against kflash.py's source and unit-tested at the framing level, not yet run against a real board).

Runtime firmware (flash once per board)

Download onnx-k210-runtime.bin -- a compiled, checksummed image (see ../firmware/runtime/README.md) that reads whatever model currently sits at flash address 0x00C00000 and runs one sanity inference at boot. Flash it at 0x0 below; swap models afterward by flashing just a .kmodel at 0x00C00000 -- see the flash-address field's note and the "skip erase" checkbox's warning below before doing that a second time.

Candidate models

This page only flashes an already-built .bin — there is no onnx→kmodel (nncase) conversion step or firmware recipe here yet (see ../README.md's follow-ups). These are the vision models to build that pipeline against once it exists (Maix Amigo has a camera; M5StickV's is often flaky). Each link opens the onnxsim model converter pre-filled with that model, to fetch/simplify/quantize the ONNX starting point.

ModelSizeWhy
mlcommons-MobileNetV1-0.25-VisualWakeWords-int8-onnx 358 KB Person detection (binary) — the natural "hello world" for K210's KPU + a camera
mlcommons-ResNet8-CIFAR10-int8-onnx 113 KB Tiny 10-class image classifier, MLPerf Tiny reference — good sanity check
tensorflow-MobileNetV1-0.25-ImageNet-224-uint8-onnx 530 KB Full 1000-class ImageNet classifier — matches Sipeed's own official K210 MobileNet demo shape
tensorflow-MobileNetV1-0.5-ImageNet-224-uint8-onnx 1.4 MB Wider/more-accurate MobileNet if the KPU weight budget allows

Checked but not recommended: google-coral-DeepLabV3-* (883 KB–1.7 MB, segmentation output handling adds real complexity) and mediapipe-EfficientDet-Lite0 (4.1 MB int8 — too big for K210's practical KPU/SRAM budget). These are community re-exports (the ketiswp Hub org), not the original MLCommons/Google accounts — spot-check one before trusting it on hardware.
