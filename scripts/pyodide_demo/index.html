onnxsim WebAssembly demo

onnxsim's compiled C++ extension, running for real inside Pyodide, in your browser.

Scope note: this demonstrates onnxsim's compiled onnxsim_cpp2py_export extension running under Pyodide and transforming real .onnx files client-side. It does not run the full onnxsim.simplify() pipeline yet -- that needs the Python onnx package, and PyPI's only onnx wasm wheel (1.22.0) is tagged for a different Pyodide ABI epoch (pyemscripten_2025_0) than this page's Pyodide 314.0.5 (2026_0), so micropip.install("onnx") fails. What is real here: parsing your uploaded model and running one of onnxsim's own native quantization/precision-conversion passes on it -- these operate on raw ONNX bytes using onnxsim's statically-linked onnx copy and need no Python onnx package at all.
Why not full simplify() -- the exact error 
ValueError: Wheel was built with Emscripten vpyemscripten.2025.0 but Pyodide was built with Emscripten v5.0.3

(no other onnx release on PyPI has a matching-epoch wasm wheel; onnx's own
numpy/protobuf/ml_dtypes dependencies additionally have no PyPI wasm wheels
at all, only Pyodide's own CDN-hosted package repo -- a compounding gap,
not just a version off-by-one.)
